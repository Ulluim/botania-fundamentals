# Security Policy

## Supported Versions

| Version | Supported |
|----------|------------|
| Latest Release | ✅ |
| Older Versions | ❌ |

---

## Reporting Security Issues

If you discover:
- Duplication exploits
- Crashes
- Severe bugs
- Data corruption
- Performance vulnerabilities
- Security problems

please report them privately instead of creating a public issue.

---

## Required Information

When reporting an issue, please include:

- Minecraft version
- Forge version
- Botania version
- Botania Fundamentals version
- Full mod list
- Crash logs
- Reproduction steps
- Screenshots or videos if possible

---

## Response Policy

Reports will be reviewed as quickly as possible.

Critical issues such as dupes, crashes, or exploits will receive priority fixes.

---

## Responsible Disclosure

Please avoid publicly sharing severe exploits before they are fixed.

* Minor issues → GitHub Issues
