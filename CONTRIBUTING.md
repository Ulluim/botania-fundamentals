# Contributing to Botania Fundamentals

Thank you for your interest in contributing to Botania Fundamentals.

## Before Opening an Issue

Please make sure to:
- Use the latest version of the addon
- Check existing issues first
- Provide logs when reporting crashes
- Include reproduction steps

## Reporting Bugs

When reporting bugs:
- Describe the issue clearly
- Explain how to reproduce it
- Include screenshots or logs if possible
- Mention your Minecraft and Forge versions

## Suggesting Features

Feature requests are welcome.

Please explain:
- What problem the feature solves
- How it should work
- Why it would improve gameplay or performance

## Pull Requests

When submitting pull requests:
- Keep code clean and documented
- Avoid unnecessary changes
- Test features before submitting
- Follow the project's style and goals

## Project Goals

Botania Fundamentals aims to:
- Improve Botania's early-game experience
- Reduce unnecessary grind
- Improve performance in large setups
- Stay vanilla-friendly

Thank you for contributing.
